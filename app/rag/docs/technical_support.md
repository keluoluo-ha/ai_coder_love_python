# 技术支持与常见故障排查

## 网站在线客服组件不显示

### 问题描述

用户在网页中嵌入了云客服 Pro 的在线客服 JS 代码，但页面上看不到客服窗口。

### 排查步骤

1. 检查 JS 代码是否正确嵌入：打开浏览器开发者工具（F12），在 Console 标签页中查看是否有报错信息
2. 检查 CSP 策略：如果网站设置了 Content-Security-Policy，需要将 cloudcs-pro.com 加入白名单
3. 检查渠道状态：登录后台"渠道管理 > 网站客服"，确认渠道状态为"已启用"
4. 检查域名白名单：确保嵌入页面的域名已添加到渠道的域名白名单中
5. 清除浏览器缓存后重新访问

### 常见原因

- JS 代码位置错误：应嵌入在 `</body>` 标签之前
- 域名未添加白名单：后台"渠道管理 > 域名设置"中添加
- 浏览器插件拦截：广告拦截插件可能屏蔽客服组件

## 微信公众号消息收不到

### 问题描述

用户通过微信公众号发送消息，但云客服 Pro 后台没有收到消息。

### 排查步骤

1. 检查公众号授权状态：后台"渠道管理 > 微信公众号"，查看授权是否过期
2. 检查服务器配置：公众号后台"开发 > 基本配置 > 服务器配置"，确认 URL 和 Token 正确
3. 检查 IP 白名单：公众号后台的 IP 白名单需添加云客服 Pro 服务器 IP
4. 重新授权：如授权过期，点击"重新授权"按钮，公众号管理员扫码确认

### 常见原因

- 授权 token 过期：微信公众号授权有效期 1 年，到期需重新授权
- 公众号类型不符：订阅号不支持客服消息接口，需服务号
- 服务器配置被修改：公众号后台的服务器配置被其他开发者改动

## API 调用返回 401 未授权

### 问题描述

调用云客服 Pro API 时返回 401 Unauthorized 错误。

### 排查步骤

1. 检查 API Key：后台"设置 > 开发者设置 > API 密钥"，确认使用的 Key 正确且未过期
2. 检查请求头：确保请求头包含 `Authorization: Bearer YOUR_API_KEY`
3. 检查 API Key 权限：确认 Key 的权限范围包含调用的接口
4. 检查调用频率：专业版每日 10000 次限制，超出后返回 429

### 解决方案

- API Key 过期：重新生成新的 Key
- 权限不足：在后台修改 Key 的权限范围
- 频率超限：升级套餐或等待次日重置

## 聊天记录导出失败

### 问题描述

用户在后台导出聊天记录时，提示导出失败或文件下载不完整。

### 排查步骤

1. 检查数据量：单次导出不超过 10 万条记录，超过请按时间段分批导出
2. 检查网络：导出大文件需要稳定网络，建议使用有线网络
3. 检查浏览器：建议使用 Chrome 或 Edge 最新版本
4. 尝试小范围导出：先导出 1 天的数据测试是否成功

### 解决方案

- 数据量过大：缩小时间范围分批导出
- 浏览器兼容问题：更换 Chrome 浏览器
- 后台处理超时：联系客服协助导出，提供时间段和筛选条件

## AI 智能回复不准确

### 问题描述

开启 AI 智能回复后，回复内容与用户问题不相关或不准确。

### 优化建议

1. 完善知识库：进入"智能客服 > 知识库"，补充产品相关文档（FAQ、操作手册、政策条款）
2. 调整回复策略：
   - 保守模式：仅在知识库匹配度高于 80% 时自动回复，否则转人工
   - 平衡模式：匹配度高于 60% 时自动回复
   - 积极模式：所有问题均尝试 AI 回复，低匹配度时标注"建议人工确认"
3. 设置兜底话术：当 AI 无法回答时，自动回复"这个问题我需要转给人工客服，请稍候"
4. 持续训练：定期查看 AI 回复记录，标记不满意回复，系统会自动优化

## 移动端 App 无法登录

### 问题描述

云客服 Pro 移动端 App（iOS / Android）无法登录，提示"网络错误"或"账号不存在"。

### 排查步骤

1. 检查网络连接：切换 WiFi / 4G 网络测试
2. 检查 App 版本：前往应用商店更新到最新版本
3. 检查账号状态：确认账号未被冻结或注销
4. 检查服务器地址：私有化部署用户需在登录页设置服务器地址
5. 清除 App 缓存：手机设置 > 应用管理 > 云客服 Pro > 清除缓存

### 解决方案

- 版本过低：更新到最新版
- 私有化部署：登录页点击"高级设置"填写服务器地址
- 账号问题：联系管理员确认账号状态
